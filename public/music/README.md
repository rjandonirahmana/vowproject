# Musik latar bawaan

Letakkan berkas MP3 **royalty-free / berlisensi** di folder ini dengan nama
persis seperti `slug` di `src/web/themes.rs` (`SONGS`):

| Berkas                   | Judul di katalog                    |
|--------------------------|-------------------------------------|
| `kisah-romantis.mp3`     | Kisah Romantis – Instrumental Piano |
| `canon-in-d.mp3`         | Canon in D – Strings & Harp         |
| `gending-sriwijaya.mp3`  | Gending Sriwijaya & Jawa Akustik    |
| `thousand-years.mp3`     | A Thousand Years – Cello Duet       |
| `akad-fingerstyle.mp3`   | Akad – Fingerstyle Guitar           |

Berkas yang absen tidak membuat error — pemutar hanya diam. Usahakan
< 3 MB per lagu (128 kbps cukup) supaya cepat dimuat di HP tamu.
